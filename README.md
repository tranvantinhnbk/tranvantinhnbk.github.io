# General Engineering

A personal blog exploring how things work across engineering and science—from mathematics, physics, and biology to computer science, open-source projects, and hands-on experiments.

## Topics

- Mathematics, physics, and biology
- Computer science and software engineering
- Engineering across disciplines
- Open-source investigations and contributions
- Experiments, models, and practical notes

## Website

Angular frontend in `github-blog/`, intended for static hosting on GitHub Pages.

```bash
cd github-blog
npm ci
npm start
```

Build: `npm run build`.

## For contributors and agents

- Read applicable `AGENTS.md` instructions and inspect existing work first.
- Keep explanations clear, use concrete examples, and cite sources.
- Separate hypotheses from verified results.
- Keep changes focused and validate what changed.
- For ongoing work, save brief decisions and next steps in `docs/sessions/` as needed.
