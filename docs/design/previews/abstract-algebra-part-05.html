Mathematics · Abstract Algebra · Part 5

Generated subgroups and cyclic groups.

Draft lesson and proposed interaction for author review.

In Part 4, we chose a subset and checked whether it was a subgroup. Now we start with one element and ask: what must a subgroup contain if it contains that element?

By the end: construct the subgroup generated by one element, explain what cyclic means, and distinguish the order of an element from the size of the surrounding group.

Start with 2 under addition

Work inside (Z,+)(\mathbb Z,+)(Z,+). Suppose a subgroup contains 222.

Closure forces it to contain 2+2=42+2=42+2=4, then 4+2=64+2=64+2=6, and every positive multiple of 222. It must also contain the identity 000 and the inverse −2-2−2. Repeating addition with −2-2−2 gives every negative multiple.

So it must contain

⟨2⟩={2n∣n∈Z}=2Z.\langle 2\rangle=\{2n\mid n\in\mathbb Z\}=2\mathbb Z.⟨2⟩={2n∣n∈Z}=2Z.

The angle brackets mean “the subgroup generated by.” The operation is addition here: ⟨2⟩\langle2\rangle⟨2⟩ consists of integer multiples of 222, not ordinary powers 2n2^n2n.

Part 4 established that 2Z2\mathbb Z2Z is itself a subgroup. Every subgroup containing 222 must contain all these multiples. Therefore 2Z2\mathbb Z2Z is the smallest subgroup containing 222, where “smallest” means contained in every other such subgroup.

Forward repetition alone would miss the negative multiples. A subgroup includes inverses as well.

Powers mean repeated group operation

For a general group (G,∗)(G,\ast)(G,∗) and a∈Ga\in Ga∈G, use multiplicative notation:

a0=e,a1=a,a2=a∗a.a^0=e,\qquad a^1=a,\qquad a^2=a\ast a.a0=e,a1=a,a2=a∗a.

For positive nnn, ana^nan combines nnn copies of aaa. Define a−n=(a−1)na^{-n}=(a^{-1})^na−n=(a−1)n. Associativity lets us regroup these repeated operations; we do not need the whole group to be commutative.

For integers m,nm,nm,n, powers of the same element obey

am∗an=am+n,(an)−1=a−n.a^m\ast a^n=a^{m+n},\qquad (a^n)^{-1}=a^{-n}.am∗an=am+n,(an)−1=a−n.

For nonnegative exponents, the first rule joins repeated copies of aaa. For negative exponents, adjacent aaa and a−1a^{-1}a−1 cancel, giving the same rule. The second follows because an∗a−n=a0=ea^n\ast a^{-n}=a^0=ean∗a−n=a0=e in either order.

In an additive group, replace ana^nan by nanana, eee by 000, and a−1a^{-1}a−1 by −a-a−a. These symbols describe the same pattern using the notation appropriate to the operation.

The subgroup generated by one element

Definition — Generated subgroup. For a∈Ga\in Ga∈G,

⟨a⟩={an∣n∈Z}.\langle a\rangle=\{a^n\mid n\in\mathbb Z\}.⟨a⟩={an∣n∈Z}.

Proposition. This is the smallest subgroup of GGG containing aaa.

Proof. It is nonempty because a0=ea^0=ea0=e belongs to it. For am,an∈⟨a⟩a^m,a^n\in\langle a\rangleam,an∈⟨a⟩,

am∗(an)−1=am−n∈⟨a⟩.a^m\ast(a^n)^{-1}=a^{m-n}\in\langle a\rangle.am∗(an)−1=am−n∈⟨a⟩.

The subgroup test from Part 4 shows that ⟨a⟩≤G\langle a\rangle\le G⟨a⟩≤G. It contains a=a1a=a^1a=a1. Every subgroup containing aaa must contain its inverse, the identity, and all their repeated products, so it contains every ana^nan. □\square□

The generated subgroup depends on the operation. Always say which group you are working in.

A quarter-turn generates every square rotation

Return to the rotation group

G={e,r,r2,r3},r4=e,G=\{e,r,r^2,r^3\},\qquad r^4=e,G={e,r,r2,r3},r4=e,

where rrr is a counterclockwise quarter-turn. Repetition gives

e, r, r2, r3, e, r,…e,\ r,\ r^2,\ r^3,\ e,\ r,\ldotse, r, r2, r3, e, r,…

Negative powers add no new rotations: r−1=r3r^{-1}=r^3r−1=r3. Consequently ⟨r⟩=G\langle r\rangle=G⟨r⟩=G.

Starting from a half-turn gives a different result:

e, r2, e, r2,…e,\ r^2,\ e,\ r^2,\ldotse, r2, e, r2,…

Thus ⟨r2⟩={e,r2}\langle r^2\rangle=\{e,r^2\}⟨r2⟩={e,r2}. We can reach the identity and the half-turn, but neither quarter-turn. The same ambient group contains elements that generate different subgroups.

Cyclic means one generator

Definition — Cyclic group. A group GGG is cyclic if G=⟨a⟩G=\langle a\rangleG=⟨a⟩ for some a∈Ga\in Ga∈G. Such an aaa is called a generator of GGG.

  • The square-rotation group is cyclic, generated by rrr.
  • (Z,+)(\mathbb Z,+)(Z,+) is cyclic, generated by 111 or −1-1−1.
  • (2Z,+)(2\mathbb Z,+)(2Z,+) is cyclic, generated by 222 or −2-2−2.

The element 222 generates the even integers, but does not generate all of Z\mathbb ZZ. Whether an element generates the whole group depends on which group we mean.

“Cyclic” does not require a finite loop. The integers under addition are an infinite cyclic group: repeated positive additions of 111 never return to 000.

Every cyclic group is abelian. Indeed, if its elements are ama^mam and ana^nan, then

am∗an=am+n=an+m=an∗am.a^m\ast a^n=a^{m+n}=a^{n+m}=a^n\ast a^m.am∗an=am+n=an+m=an∗am.

This proves commutativity within a subgroup generated by one element, even when its surrounding group is not abelian.

Order: when do we first return to the identity?

Definition — Order of an element. The order of aaa, written ord⁡(a)\operatorname{ord}(a)ord(a), is the smallest positive integer kkk such that ak=ea^k=eak=e. If no such positive integer exists, aaa has infinite order.

For square rotations:

Element First positive return to identity Order
eee e1=ee^1=ee1=e 111
rrr r4=er^4=er4=e 444
r2r^2r2 (r2)2=e(r^2)^2=e(r2)2=e 222
r3r^3r3 (r3)4=e(r^3)^4=e(r3)4=e 444

For the last row, the successive powers are r3,r2,r,er^3,r^2,r,er3,r2,r,e, so no earlier positive return occurs.

Under integer addition, 222 has infinite order: the equation 2k=02k=02k=0 has no positive integer solution. Although 0⋅2=00\cdot2=00⋅2=0, the definition explicitly requires a positive number of repetitions.

The order of a group means its number of elements, written ∣G∣|G|∣G∣. The square-rotation group has order 444, while its element r2r^2r2 has order 222.

Why order counts the generated subgroup

If aaa has finite order kkk, then

⟨a⟩={e,a,a2,…,ak−1}.\langle a\rangle=\{e,a,a^2,\ldots,a^{k-1}\}.⟨a⟩={e,a,a2,…,ak−1}.

To see why these exhaust the powers, write any integer n=qk+sn=qk+sn=qk+s with 0≤s<k0\le s<k0≤s<k. Then an=(ak)q∗as=asa^n=(a^k)^q\ast a^s=a^san=(ak)q∗as=as.

They are distinct: if ai=aja^i=a^jai=aj for 0≤i<j<k0\le i<j<k0≤i<j<k, cancellation gives aj−i=ea^{j-i}=eaj−i=e, contradicting the minimality of kkk.

Thus ∣⟨a⟩∣=k|\langle a\rangle|=k∣⟨a⟩∣=k. If aaa has infinite order, distinct integer exponents give distinct powers by the same cancellation argument. Its generated subgroup is then infinite.
