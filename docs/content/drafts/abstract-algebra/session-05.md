# Part 5: Generated subgroups and cyclic groups

In Part 4, we chose a subset and checked whether it was a subgroup. Now we start with one element and ask: what must a subgroup contain if it contains that element?

**By the end:** construct the subgroup generated by one element, explain what cyclic means, and distinguish the order of an element from the size of the surrounding group.

## Start with 2 under addition

Work inside $(\mathbb Z,+)$. Suppose a subgroup contains $2$.

Closure forces it to contain $2+2=4$, then $4+2=6$, and every positive multiple of $2$. It must also contain the identity $0$ and the inverse $-2$. Repeating addition with $-2$ gives every negative multiple.

So it must contain

$$
\langle 2\rangle=\{2n\mid n\in\mathbb Z\}=2\mathbb Z.
$$

The angle brackets mean “the subgroup generated by.” The operation is addition here: $\langle2\rangle$ consists of integer multiples of $2$, not ordinary powers $2^n$.

Part 4 established that $2\mathbb Z$ is itself a subgroup. Every subgroup containing $2$ must contain all these multiples. Therefore $2\mathbb Z$ is the smallest subgroup containing $2$, where “smallest” means contained in every other such subgroup.

Forward repetition alone would miss the negative multiples. A subgroup includes inverses as well.

## Powers mean repeated group operation

For a general group $(G,\ast)$ and $a\in G$, use multiplicative notation:

$$
a^0=e,\qquad a^1=a,\qquad a^2=a\ast a.
$$

For positive $n$, $a^n$ combines $n$ copies of $a$. Define $a^{-n}=(a^{-1})^n$. Associativity lets us regroup these repeated operations; we do not need the whole group to be commutative.

For integers $m,n$, powers of the same element obey

$$
a^m\ast a^n=a^{m+n},\qquad (a^n)^{-1}=a^{-n}.
$$

For nonnegative exponents, the first rule joins repeated copies of $a$. For negative exponents, adjacent $a$ and $a^{-1}$ cancel, giving the same rule. The second follows because $a^n\ast a^{-n}=a^0=e$ in either order.

In an additive group, replace $a^n$ by $na$, $e$ by $0$, and $a^{-1}$ by $-a$. These symbols describe the same pattern using the notation appropriate to the operation.

## The subgroup generated by one element

**Definition — Generated subgroup.** For $a\in G$,

$$
\langle a\rangle=\{a^n\mid n\in\mathbb Z\}.
$$

**Proposition.** This is the smallest subgroup of $G$ containing $a$.

**Proof.** It is nonempty because $a^0=e$ belongs to it. For $a^m,a^n\in\langle a\rangle$,

$$
a^m\ast(a^n)^{-1}=a^{m-n}\in\langle a\rangle.
$$

The subgroup test from Part 4 shows that $\langle a\rangle\le G$. It contains $a=a^1$. Every subgroup containing $a$ must contain its inverse, the identity, and all their repeated products, so it contains every $a^n$. $\square$

The generated subgroup depends on the operation. Always say which group you are working in.

## A quarter-turn generates every square rotation

Return to the rotation group

$$
G=\{e,r,r^2,r^3\},\qquad r^4=e,
$$

where $r$ is a counterclockwise quarter-turn. Repetition gives

$$
e,\ r,\ r^2,\ r^3,\ e,\ r,\ldots
$$

Negative powers add no new rotations: $r^{-1}=r^3$. Consequently $\langle r\rangle=G$.

Starting from a half-turn gives a different result:

$$
e,\ r^2,\ e,\ r^2,\ldots
$$

Thus $\langle r^2\rangle=\{e,r^2\}$. We can reach the identity and the half-turn, but neither quarter-turn. The same ambient group contains elements that generate different subgroups.

## Cyclic means one generator

**Definition — Cyclic group.** A group $G$ is cyclic if $G=\langle a\rangle$ for some $a\in G$. Such an $a$ is called a generator of $G$.

- The square-rotation group is cyclic, generated by $r$.
- $(\mathbb Z,+)$ is cyclic, generated by $1$ or $-1$.
- $(2\mathbb Z,+)$ is cyclic, generated by $2$ or $-2$.

The element $2$ generates the even integers, but does not generate all of $\mathbb Z$. Whether an element generates the whole group depends on which group we mean.

“Cyclic” does not require a finite loop. The integers under addition are an infinite cyclic group: repeated positive additions of $1$ never return to $0$.

Every cyclic group is abelian. Indeed, if its elements are $a^m$ and $a^n$, then

$$
a^m\ast a^n=a^{m+n}=a^{n+m}=a^n\ast a^m.
$$

This proves commutativity within a subgroup generated by one element, even when its surrounding group is not abelian.

## Order: when do we first return to the identity?

**Definition — Order of an element.** The order of $a$, written $\operatorname{ord}(a)$, is the smallest positive integer $k$ such that $a^k=e$. If no such positive integer exists, $a$ has infinite order.

For square rotations:

| Element | First positive return to identity | Order |
| --- | --- | --- |
| $e$ | $e^1=e$ | $1$ |
| $r$ | $r^4=e$ | $4$ |
| $r^2$ | $(r^2)^2=e$ | $2$ |
| $r^3$ | $(r^3)^4=e$ | $4$ |

For the last row, the successive powers are $r^3,r^2,r,e$, so no earlier positive return occurs.

Under integer addition, $2$ has infinite order: the equation $2k=0$ has no positive integer solution. Although $0\cdot2=0$, the definition explicitly requires a positive number of repetitions.

The **order of a group** means its number of elements, written $|G|$. The square-rotation group has order $4$, while its element $r^2$ has order $2$.

## Why order counts the generated subgroup

If $a$ has finite order $k$, then

$$
\langle a\rangle=\{e,a,a^2,\ldots,a^{k-1}\}.
$$

To see why these exhaust the powers, write any integer $n=qk+s$ with $0\le s<k$. Then $a^n=(a^k)^q\ast a^s=a^s$.

They are distinct: if $a^i=a^j$ for $0\le i<j<k$, cancellation gives $a^{j-i}=e$, contradicting the minimality of $k$.

Thus $|\langle a\rangle|=k$. If $a$ has infinite order, distinct integer exponents give distinct powers by the same cancellation argument. Its generated subgroup is then infinite.
